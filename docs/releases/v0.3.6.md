# 在应用内下载更新

- 按 Coop 的更新流程，检查版本后直接在客户端内下载，显示进度和已下载大小。
- 关闭更新窗口后继续下载，重新打开保留进度。可取消、重试，下载完成后显示“打开安装程序”。
- 自动匹配 Windows、Apple Silicon Mac 或 Intel Mac 安装包；下载完成及打开前核对文件大小和 SHA-256。
- Windows 改用安装程序；Mac 新增 DMG，打开后拖入 Applications 替换。保留 Mac ZIP 供旧版本下载入口使用。
- 当前版本、最新版本、更新内容和失败原因集中显示，更新请求不携带报销登录凭证。

从 v0.3.5 或更早版本升级时，请先通过原来的下载按钮安装这一次。之后即可使用新的应用内更新流程。

此版本仅更新客户端，沿用现有后端。安装前请保存正在编辑的内容。
