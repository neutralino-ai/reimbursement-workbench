# 合并报销材料与截图正文编排

- 总览勾选两笔费用，点击“合并准备材料”。两笔 USD 200 可共用一份情况说明 Word 和一份整合 PDF；分组显示为一个可展开的行。
- 每笔按各自发票日期的中行折算价换算，合计限额人民币 4000 元。缺汇率、超限、费用变化或与既有确认金额不同会拦截，不自动改写历史金额。
- 科研截图可选择、预览，在 PDF 和 Word 的“科研用途说明”正文内呈现，不再放到所有附件最后。Word 内嵌中文字体。
- 合并包检查备妥后只计一份必交 PDF，可在包内登记交财务；原始费用、付款、ARP 和审批记录仍分别保留。
- 修复准备材料窗口未修改或已保存后仍提示“放弃修改”的问题，确有未保存内容仍会提醒。
- 保留 0.3.2 的附件预览、选择文件后手动上传、上传前移除，以及允许删除尚未提交的误传附件功能。

需要配套私有后端 0.3.3。更新不会自动分组、确认金额或改写历史报销记录；五月旧材料的具体汇率更正仍需单独核对。

## 安装

Apple Silicon Mac：`Reimbursement-0.3.3-mac-arm64.zip`。Intel Mac：`Reimbursement-0.3.3-mac-x64.zip`。Windows：`Reimbursement-0.3.3-win-x64.exe`。

请核对同一 Release 中的 `SHA256SUMS`。前端公开发布，后端源码、凭证及个人材料不包含在客户端发行包中。
