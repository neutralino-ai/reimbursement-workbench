# 合并报销进度与申报 ZIP

- 合并报销区按六种状态显示未达条件、可选择合并、材料准备、材料确认、已提交和财务审核完成。未到材料准备阶段、缺有效汇率或无法组成限额内组合的费用不会误显示为可合并。
- 已确认的新版合并申请包可在合并报销区直接生成 ZIP，任务完成后下载。ZIP 包含一份报销说明 PDF 和各笔发票原件；付款记录、申请理由和截图在说明 PDF 中。生成 ZIP 不改变交财务或财务审核状态。
- 旧版或已失效的申请材料继续提示更新，不作为可下载的当前申请包。

## 图片压缩与连接状态改进

- 上传较大的 PNG、JPEG、WebP 截图时，客户端在本机生成适当压缩的 JPEG；若压缩收益不足，则保留原文件。上传记录注明处理前后大小，服务器只接收实际上传的版本。
- 工作区和自动化状态保存在当前登录会话的本地缓存中。页面可立即显示最近状态，并在可见时定期同步；写操作、退出登录及切换服务器会清除缓存。
- 降低空闲时的状态轮询频率；任务运行时加快刷新。DeepSeek 连接检查允许更长的模型响应时间，并将远程 API 超时与其他连接错误区分。

服务器已单独部署图片迁移和状态查询优化。Windows 使用 EXE 安装程序；Mac 提供经 Developer ID 签名与公证的 Apple Silicon / Intel DMG 和 ZIP。iOS 通过现有内部 TestFlight 流程分发，安装方式见附件 iOS-Installation.md。
