# 单笔多阶段表格与合并材料上传入口修复

- 单笔报销恢复“费用、发票准备、实付款、申报材料、交财务、财务审核”六列。仅当前阶段显示浅蓝色；窄屏横向滚动时费用列固定。
- 需要非单位抬头情况说明的合并包，在第三阶段直接显示“上传说明”。点击后聚焦顶部上传面板，可上传已有的领导签字说明，解释报销人或地址不是单位的原因。
- 每份合并材料关联一份说明；上传成功后自动选中新文件，仍须核对领导签字与对应发票。上传期间保留窗口及操作保护，手机弹窗完整显示文件与确认控件。

已通过 82 项客户端测试、类型检查和生产构建；使用真实组件与隔离模拟数据检查桌面/390px 窄屏布局、文件选择上传、签字件选择及材料备妥请求。实际报销文件与财务状态未在界面测试中改写。

Windows 提供 EXE；macOS 提供经过签名、公证的 Apple Silicon / Intel DMG 和 ZIP；iOS 通过内部 TestFlight 分发。
