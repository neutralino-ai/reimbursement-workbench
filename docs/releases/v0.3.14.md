# 合并准备更可靠，状态更清楚

- 合并准备窗口会显示当前操作、已等待时间和最近一次成功刷新；AI 草稿、PDF 生成、上传和下载都有明确进度或超时提示。
- DeepSeek 生成的共同说明草稿现在可以直接修改，并可暂存到本机；共同说明、草稿文本和截图勾选可恢复。暂存只保存在当前设备，不包含尚未上传的附件。
- 无法执行的按钮会显示具体原因，例如缺少付款核验、材料仍在上传、草稿过期或正在生成。
- 合并材料备妥后会离开“合并准备”区，并在费用列表中合并显示为一条；提交或进入财务流程的费用不再出现在合并准备区。可展开查看各月明细。
- 超时后保留用户编辑内容并提示刷新核对，减少重复提交风险。

本次为客户端更新，沿用现有服务器 API。Windows 使用 EXE 安装程序；Mac 提供经 Developer ID 签名与公证的 Apple Silicon / Intel DMG 和 ZIP。iOS 通过现有内部 TestFlight 流程分发，安装方式见附件 iOS-Installation.md。
