# 报销工作台 0.3.2

- 待上传和已上传附件增加缩略图及明确的“点击预览”入口；点击图片或文件名即可查看。
- 图片在应用内显示大图，支持放大、缩小、适应窗口和原始尺寸；放大后可滚动查看细节。
- PDF 提供独立预览入口，可翻页、缩放；不支持直接显示的格式可下载原件查看。
- 待上传文件只在本机预览，点击“提交上传”才保存；关闭预览不会上传或删除文件。
- 已上传附件沿用登录鉴权读取，关闭预览释放临时资源。预览后仍由用户在附件列表决定是否删除。

本版本仅更新公开客户端，兼容私有后端 0.3.1，无需迁移账本。macOS 包为 ad-hoc 签名，未公证；下载后可用 SHA256SUMS 校验。
