# 修复本机暂存后的窗口行为

- “暂存到本机”改为“暂存并关闭”：共同说明、修改后的 DeepSeek 草稿和截图勾选保存成功后立即关闭材料窗口。
- 暂存失败时保留窗口及输入内容，在顶部显示具体原因，避免无反馈或误关窗口。
- 有科研截图或签字说明尚未上传时，先提示文件无法缓存；可继续编辑，或明确选择暂存文字并关闭。附件正在上传时暂不能关闭。

验证：客户端 86 项测试、类型检查和生产构建通过。使用真实 React 组件与合成数据进行界面回归，核对保存后关闭、重新打开与刷新后的完整恢复、存储空间不足时保留内容、未上传签字文件的关闭提示；未向生产台账写入测试数据。

Windows 提供 EXE；macOS 提供经过签名、公证的 Apple Silicon / Intel DMG 和 ZIP；iOS 通过内部 TestFlight 分发。
