# 签字情况说明自动核查与 ZIP 流程修复

- 上传已有的领导签字说明后，服务器自动调用 DeepSeek 核查可见签字、报销人或地址不是单位的原因，以及本份材料中相关发票的覆盖范围。
- 客户端显示核查进度、通过结果或具体问题，可主动重新核查；删除人工签字确认勾选项。AI 核查保留为 AI 结论，PDF 正文仍由用户检查确认。
- 修复“签字附件尚未关联”被误判为“PDF 来源已变化”的循环阻塞。补传独立签字附件不使正文 PDF 过期；发票、付款或正文来源变化仍会使旧材料失效。
- 每份申请包只放一份所选签字附件；通过核查并确认材料后，可生成含说明 PDF、发票原件和签字附件的 ZIP。已进入财务流程的历史材料保持原状。

验证：客户端 86 项测试、类型检查和生产构建；后端 190 项测试，另用真实 PDF/ZIP 渲染器跑 9 项流程测试。覆盖单笔/合并包、先上传/后上传、缺签字/原因不符/漏发票、并发变更和旧 ZIP 失效，验证 ZIP 内原件字节。真实组件的隔离界面验收覆盖上传、等待自动核查、材料确认及 ZIP 入口。

Windows 提供 EXE；macOS 提供经过签名、公证的 Apple Silicon / Intel DMG 和 ZIP；iOS 通过内部 TestFlight 分发。
