# 合并报销包支持 DeepSeek 整理说明

- 在“合并准备材料”中新增“DeepSeek 整理说明”。使用共同用途、各笔已有用途和勾选的科研截图，起草一份共同说明。
- AI 结果先作为独立草稿显示，点击“采用草稿到共同说明”后可继续修改；不会自动覆盖文字、确认金额或提交材料。
- 显示整理进度、缺失信息及失败原因，可关闭窗口后回来查看。重复点击复用进行中的任务，失败不会自动重试计费。
- 来源版本或截图变化时，旧结果不可采用；未保存修改和已交付材料受到保护。金额和汇率仍由程序逐笔计算。

需要配套私有后端 0.3.4，沿用已保存的 DeepSeek API 密钥。更新不改写历史记录，不自动调用模型处理个人材料。

安装包：Apple Silicon Mac `Reimbursement-0.3.4-mac-arm64.zip`，Intel Mac `Reimbursement-0.3.4-mac-x64.zip`，Windows `Reimbursement-0.3.4-win-x64.exe`。校验值见同一 Release 的 `SHA256SUMS`。
