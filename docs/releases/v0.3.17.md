# Claude 发票抬头核对与签字附件

- 上传发票时提示核对 Bill to。非 IHEP 的个人地址会提示在第三阶段准备报销材料时补充情况说明；每份申报材料一份，合并包中的相关发票可共用。
- 在单笔和合并材料准备界面上传已有的领导签字说明，选定文件并检查签字及所覆盖发票后，才能确认申请包备妥。
- 申报 ZIP 将已确认的签字说明与报销说明 PDF、发票原件分别放置。已通过财务审核的历史费用不追补。

本版不自动生成抬头说明草稿。生产记录的逐票核对由服务端 Agent 命令单独登记；客户端更新不会自行改写审批、付款或人工核验事实。Windows 提供 EXE，Mac 提供已签名及公证的 Apple Silicon / Intel DMG 和 ZIP；iOS 通过内部 TestFlight 分发。
