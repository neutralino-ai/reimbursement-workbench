# 报销工作台 0.3.1

- 上传改为先选择、预览和移除图片，再点击“提交上传”；选错文件可取消整批上传。
- 已上传的发票、付款凭证和申报用途附件可直接删除，不使用作废/恢复流程。
- 删除误传图片后，依赖它的自动核验和未提交申报草稿失效，避免继续使用旧材料。已交财务或审批引用的证据受到保护。
- 修复客户端与服务器接口不同步的问题；后端需要配套部署 server 0.3.1。
- 客户端源码公开；后端在独立私有仓库维护。安装包只包含前端，不包含账本、凭证、密钥或后端代码。
- 发行流程校验版本、测试与安装包内容，通过后发布 GitHub Release；本机安装以正式发行包为准。

macOS 提供 Apple Silicon 和 Intel 版本（ad-hoc 签名，未公证）；Windows 提供 x64 便携版。下载文件可使用 SHA256SUMS 校验。
