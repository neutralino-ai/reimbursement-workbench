# 点击流程阶段筛选费用

- Windows、Mac 和 iPhone 的五个阶段统计均可点击，只显示前序已完成、当前步骤尚未完成的费用。
- 保留各阶段已完成数量，另显示恰好卡在该阶段的待办数量；选中后高亮，再次点击或选择“费用 / 全部”取消筛选。
- 阶段筛选保留搜索和发票日期排序，合并包自动展开符合条件的记录。切换进度下拉框或“全部 / 待处理 / 已报销”时清除阶段筛选。
- 原始材料采集状态分别按供应商及对应发票判断；财务审核中和已报销记录继续使用既有自动完成规则。
- 包含最新主分支的手机紧凑布局、服务标识与截图收件箱。

Windows 使用 EXE 安装程序；Mac 提供经 Developer ID 签名与公证的 Apple Silicon / Intel DMG 和 ZIP。iOS 经现有内部 TestFlight 流程分发，安装方式见附件 iOS-Installation.md。

本次为客户端更新，沿用现有服务器 API。请先保存正在编辑的内容再安装。
