# 申报 ZIP 分开保存说明和发票

- ZIP 内包含报销说明 PDF 和对应发票原件；发票页面不再嵌入说明 PDF。
- 付款、汇率查询和科研用途截图继续保留在说明中，Word 仍可单独下载。
- 单笔和多笔合并报销均支持，交付清单按“说明 PDF＋各笔发票”统计。
- 旧版文件保留。按新格式打包前，请重新生成并检查说明；已经进入财务审核的历史材料无需重做。

需配套后端 0.3.6。更新不会自动调用模型、确认材料或交付给财务。

安装包：Apple Silicon Mac `Reimbursement-0.3.5-mac-arm64.zip`，Intel Mac `Reimbursement-0.3.5-mac-x64.zip`，Windows `Reimbursement-0.3.5-win-x64.exe`。校验值见同一 Release 的 `SHA256SUMS`。
