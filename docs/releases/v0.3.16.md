# 合并报销进度表与单笔列表

- 合并报销区改为六列进度表。每行是一笔待合并费用或一组合并报销，当前状态、已完成阶段和后续阶段分别显示；点击上方状态统计可筛选对应行。
- 达到合并条件的费用可直接在第二列勾选。材料确认完成的合并组在第四列提供报销说明 PDF，以及生成、下载申报 ZIP 的操作。
- 下方费用区改为每笔一行的单列列表，只显示未参与当前合并组的单笔费用。合并包行、展开明细和合并选择入口统一移至上方；单笔记录仍可打开完整报销流程。
- 桌面和手机共用状态筛选与单笔列表；窄屏可横向查看合并进度表。

本次仅更新客户端界面，沿用现有服务器 API。Windows 使用 EXE 安装程序；Mac 提供经 Developer ID 签名与公证的 Apple Silicon / Intel DMG 和 ZIP。iOS 通过现有内部 TestFlight 流程分发，安装方式见附件 iOS-Installation.md。
