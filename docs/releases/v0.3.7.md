# Apple 正式签名发布与 iOS TestFlight

- Mac 安装包要求 Developer ID 签名、Apple 公证以及 Gatekeeper 验证；缺少凭据会停止发布，不降级成临时签名。
- iOS 通过 TestFlight 分发。打开附件 `iOS-Installation.md` 获取安装入口；需要 iOS 18 或更高版本和已有报销服务器账号。
- 完整 iOS 原生工程、前端源码及构建脚本继续公开；不发布无法直接安装的 App Store IPA。
- iOS 构建自动同步客户端版本号、重新生成并核对前端资源，避免原生版本号或资源陈旧。
- 保留现有 Mac/Windows 更新方式。不更新后端，不改变报销记录，也不会自动提交 App Store 正式审核。

TestFlight 安装资格、可用构建及名额以 Apple 安装页面为准。所有附件均列入 `SHA256SUMS`。
